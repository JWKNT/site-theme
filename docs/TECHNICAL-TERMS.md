# Technical terms for original site writing

Use these project terms in their stated subject fields.
This register records domain usage. It is not an additional list of general STE dictionary words.
Preserve exact labels, symbols, names, and imported text when the writing policy protects them.

| Subject | Technical nouns | Usage |
| --- | --- | --- |
| Mathematics | graph, vertex, edge, cycle, path, forest, cycle space, cycle rank, pancyclic graph | Keep each definition and its hypotheses exact. A cycle is not an arbitrary even edge set. |
| Proofs | witness, cut, correlation, expectation, second moment, upper bound, lower bound, recurrence, iterated logarithm | Preserve implication direction, quantifiers, probability spaces, and asymptotic qualifications. |
| Solvers | clue, candidate, deduction, solution, segment, shaded cell, number base, cipher digit | Distinguish every solution, some solutions, no solution, and an unresolved result. |
| A38 | pass, gray cell, route, direction | A pass is a puzzle resource. A pass cell consumes it. Keep acquisition and consumption distinct. |
| Translation | canonical source, canonical target, authority file, stable ID, corpus, register, character voice, reveal timing | These terms identify project evidence, output, and translation constraints. Preserve the source's voice in translated examples. |
| Japanese text | ruby, furigana, evidentiality, head noun, omitted subject | Keep linguistic meaning and source examples exact. |
| Builds | canary test, round trip, build, idempotent patcher, review gate, markup, placeholder | Keep data contracts, output formats, release conditions, and rollback conditions exact. |
| Game Help | HP, Stamina, stat, inventory slot, stack, potion, feeding limit, auto mode | Use the implemented mechanic. State necessary actions and conditions. Preserve fictional descriptions separately. |
| Recording notes | input, undo, restart, attempt, capture, recovery frame, gameplay, playback speed | Keep measured counts and observational uncertainty. Do not infer unseen actions from a recording gap. |
| Data interfaces | estimate, confidence, report, genotype, ancestry, score, criterion, telemetry | Preserve source meaning, privacy boundaries, scientific limitations, and live-state uncertainty. |

Computer and interface technical verbs include click, enter, press, type, save, sort, filter, scroll, download, update, and validate.
Use each in a precise computer-process sense.
Mathematical verbs can include count, contract, restrict, normalize, and iterate when their technical meaning is clear.
Do not treat permission for a technical term as permission for unrelated metaphors or ordinary synonyms.
