Readable at every density

Use 18–20px for long text and 16px for dense reference text. Use 14px for regular controls and 12px for secondary metadata. Before you decrease label sizes, let the toolbar wrap. Assess plot annotations and puzzle candidates separately.

How to apply the scale

The shared stylesheet supplies defaults. A site stylesheet can override them. Change the declaration that controls the layout. Keep chart and board geometry in the site stylesheet. See the design system for ownership and exceptions.

Transitions

A subject change can use one ruled ornament. Remove adjacent section boundary rules. This prevents duplicate lines.

Principles

  • Put the material before promotional content.
  • Use type, line length, rules, and disclosures to show the information hierarchy.
  • Before you add boxes, use margins for context and whitespace for separation.
  • Reserve color for meaningful state and comparison.
  • Keep controls and content clear for keyboard use, phones, and print.
