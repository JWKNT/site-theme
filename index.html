JWKNT Site Theme

A shared, versioned design foundation for JWKNT GitHub Pages projects.

Load the shared foundation before a site-specific stylesheet:

<script src="/site-theme/v1/theme.js"></script>
<link rel="stylesheet" href="/site-theme/v1/base.css">
<link rel="stylesheet" href="assets/styles.css">

Version 1 contains the common palette, typography, document defaults, accessibility utilities, and site-header primitives.

Philosophy

The theme is a quiet frame for different kinds of work. Structure follows the material; the shared language keeps those structures related.

  • Prefer text, whitespace, alignment, and hairline rules before containers or decoration.
  • Use a neutral serif-first palette with one restrained blue and compact, square controls.
  • Add search, filters, sorting, pagination, or overlays only when the information earns them.
  • Keep stable work in the build, bound large rendered collections, and make the empty case equally intentional.
  • Treat keyboard access, visible focus, responsive hierarchy, dark mode, and reduced motion as part of the style.
