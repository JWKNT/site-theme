Controls near their results

Native labels and controls wrap as a group. This small catalogue is a working example: search or change the surface to filter it.

Dropdown markup
<label class="ui-field">Surface
  <select name="surface" data-ui-select>
    <option value="all">All surfaces</option>
    <option value="reading">Reading</option>
  </select>
</label>

The native select owns the value and form events. The shared menu adds arrow keys, Home/End, typeahead, Enter, and Escape. Without the script it remains a styled native control.

One record, in context

A native dialog handles focus containment and Escape. The shared shell keeps its close control reachable while long content scrolls.

Dialog markup
<dialog class="ui-dialog" data-dialog aria-labelledby="record-title">
  <form method="dialog" class="ui-dialog-dismiss">
    <button aria-label="Close details">×</button>
  </form>
  <div class="ui-dialog-body">
    <h2 id="record-title">Record title</h2>
    <p>Record content.</p>
  </div>
</dialog>

Use only what the page needs

Load the optional component layer after the foundation and before local styles. Behavior is enabled by explicit data attributes. Unmarked pages keep their existing behavior.

<script src="https://jehlp.net/site-theme/v2/theme.js"></script>
<link rel="stylesheet" href="https://jehlp.net/site-theme/v2/base.css">
<link rel="stylesheet" href="https://jehlp.net/site-theme/v2/components.css">
<link rel="stylesheet" href="assets/styles.css">
<script src="https://jehlp.net/site-theme/v2/components.js" defer></script>

For components added later, call window.JehlpUI?.enhance(container). Repeated calls are safe. See the full component contracts for examples and boundaries.

reusable behavior

Native dialog

Keep the record’s title, explanation, and actions together. Open with showModal() after filling the content. Close with a native method="dialog" form.

Escape returns you to the opener. Clicking inside the dialog—including its padding—keeps it open. A click begun and finished on the backdrop closes it.
